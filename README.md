# Data-Science-Mini-Project
# Student Academic Performance Analysis

## Project Overview
This project analyzes a self-created student academic performance dataset using Python. The objective is to explore the relationship between study hours, attendance, gender, and marks through data analysis and visualization.

## Objective
- Analyze student performance data.
- Study the relationship between study hours and marks.
- Examine the impact of attendance on academic performance.
- Compare marks based on gender.
- Visualize the data to derive meaningful insights.

## Dataset

- **Source:** Self-created sample dataset using Python (Pandas)
- **Dataset Name:** Student Academic Performance Dataset

### Dataset Description
The dataset contains information about 10 students with the following attributes:

- **Name** – Shashikanth
- **Gender** – Male (M) 
- **Hours_Studied** – 8
- **Attendance** – 88
- **Marks** – 85

## Key Insights

- The average marks scored by students are calculated.
- sunny is the top performer with **92 marks**.
- Kiran scored the lowest with **68 marks**.
- There is a strong positive correlation between **Hours Studied** and **Marks**.
- Students with attendance above **85%** generally achieved marks above **80**.
- Female students in this sample scored slightly higher on average than male students.

## Conclusion

The analysis shows that both study hours and attendance positively influence academic performance. Students who study more and maintain good attendance tend to achieve better marks. Data visualization makes these trends easier to understand.
